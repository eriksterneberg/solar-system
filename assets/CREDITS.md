## Processing notes
Maps were resampled, rolled to 0 deg longitude centre and re-encoded as JPEG. Pluto's colour is the PIA19956 enhanced-colour map applied to the 300 m monochrome mosaic. Mercury's default map has reduced colour saturation; the full-strength enhanced false-colour version is mercury_enhanced.jpg. Venus' cloud map is an artistic composite, not a photograph.
